# dayspann

[English](README.md) | [日本語](README.ja.md)

日々の中から、自分にとって意味のある一日を、記念日として砂金のようにすくい上げるObsidianプラグインです。

すくい上げた記念日が自分の中に増えていくことで、人生は豊かになる。dayspannは、そう考えています。

過去の記録に埋もれている出来事も、これから迎える大切な一日も、自分の手で選び取れます。すくい上げた記念日と今日を一本の線でつなぐことで、「あれからどれくらい経ったか」「その日まであとどれくらいか」という二つの日の「あいだ」が見えるようになります。そして、その「あいだ」から、自分のStoryが生まれます。

Vault全体を自動解析せず、何を記念日にするかは自分で選べます。

> [!NOTE]
> dayspannは現在、GitHubとBRATを通じて公開ベータ版を配布しています。まだObsidianのコミュニティプラグイン一覧から直接インストールすることはできません。
> テストへの参加方法と確認項目は、[ベータテストガイド](BETA_TESTING.ja.md)をご覧ください。

## 主な機能

- Markdownの編集モード・閲覧モードで選択した文章を登録
- 節目や未来の日付を手動登録
- 「あと何日」「今日」「あれから何日」へ自動分類
- 記録ごとに次の表示形式を選択
  - 日数
  - 月数
  - 年数
  - 月＋日
  - 年＋月＋日
- 3つのセクションを並べ替え
- セクションごとに折りたたみ・展開し、その状態を保存
- 記録を削除せずアーカイブし、必要なときにメイン一覧へ戻す
- 未来と過去の表示色を変更
- 保存した記録内に、登録元ノートへのクリック可能なリンクを残す
- 1件ずつ読みやすいMarkdownファイルとして保存
- デスクトップとモバイルの両方に対応

月数と年数は、30日・365日の固定換算ではなく、実際のカレンダー上で完了した月・年を数えます。

## 使い方

1. Markdownノートで残したい文章を選択します。
2. コマンドパレットから「選択した文章を登録」を実行します。編集モードでは右クリックの「dayspannに登録」も使えます。
3. 名前、基準日、表示形式を確認して登録します。
4. リボンのカレンダーアイコン、またはコマンドパレットの「一覧を開く」から確認します。

カードを選択すると、保存されたdayspann記録が開きます。選択した文章から作成した記録では、`source`プロパティのリンクから登録元ノートを開けます。カードの操作メニューから登録元ノートへ直接移動することもできます。

文章を選択せずに、誕生日、年齢の節目、記念日、期限などを「手動で登録」することもできます。既存記録の編集画面から、登録元ノートを後から選択・解除できます。

## データとプライバシー

dayspannはローカルかつオフラインで動作します。

- 外部サービスへ接続しません。
- 利用状況や解析データを収集しません。
- 広告を表示しません。
- 選択元のノートを変更しません。
- 登録内容をVault内のMarkdownファイルとして保存します。
- 設定をObsidian標準のプラグイン設定ファイルへ保存します。

新規インストール時の保存先は`dayspann`です。設定画面から変更できます。

## 名前の意味

`dayspann`は、数多くの`days`から砂金のように記念日をすくい上げ、自分の中に増やしていくことで人生を豊かにする**days + pann(ing)**という哲学を表しています。末尾に加えた`n`によって、砂金を採る動作である**panning**を、綴りからより強く想起できる名前になりました。

その結果として、すくい上げた日と今日との幅を表す**day span**という機能的な意味が生まれます。そのspanを見つめることで、自分のStoryが生まれます。

## インストール

### BRAT（ベータ期間中の推奨方法）

1. Obsidianのコミュニティプラグイン一覧から**BRAT**をインストールして有効化します。
2. **設定 → BRAT**を開き、**Add beta plugin**を選択します。
3. リポジトリとして`shingotanaka0115/dayspann`を入力します。
4. **設定 → コミュニティプラグイン**から**dayspann**を有効化します。

BRATはGitHub Releaseを確認し、今後のベータ版へ更新できます。dayspannのバージョンは`0.1.7`のように、先頭に`v`を付けない形式です。

### 手動インストール

1. GitHub Releaseから`main.js`、`manifest.json`、`styles.css`をダウンロードします。
2. `<Vault>/.obsidian/plugins/dayspann/`フォルダを作成します。
3. 3つのファイルをフォルダへコピーします。
4. Obsidianを再読み込みし、「設定 → コミュニティプラグイン」からdayspannを有効にします。

内部のプラグインIDと手動インストール時のフォルダ名は、どちらも`dayspann`です。

公式審査後は、コミュニティプラグイン一覧から直接インストールできるようになります。

## 開発

Node.js 20以上とnpmが必要です。

```bash
npm install
npm run dev
```

コミットまたはリリース前に、次を実行します。

```bash
npm run check
```

リリースに添付するファイルは`main.js`、`manifest.json`、`styles.css`です。ローカル設定の`data.json`と生成物の`main.js`は、ソース管理から除外します。
